# Restaurace U Schwarzů - Frontend

## Project Overview
Moderní web pro restauraci U Schwarzů v Brně-Řečkovicích.
Stack: React, Vite, Tailwind CSS, Framer Motion, Lucide React.

## Build Commands
- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run preview`: Preview production build

## Project Structure
- `src/components/layout`: Globální komponenty (Header, Footer, Navbar)
- `src/components/sections`: Sekce hlavní stránky (Hero, Menu, Contact)
- `src/data`: Statická data (jídelní lístek, kontaktní informace)
- `src/hooks`: Vlastní React hooky
- `src/utils`: Pomocné funkce

## Design System
- **Colors**:
  - `wood`: `#3D2B1F` (Tmavé dřevo)
  - `cream`: `#FAF9F6` (Off-white / Krémová)
  - `brick`: `#841B11` (Cihlově červená)
- **Fonts**:
  - Serif: `Playfair Display` (Nadpisy)
  - Sans: `Inter` (Text)

## Conventions
- Používej Tailwind třídy pro styling.
- Animace řeš pomocí Framer Motion.
- Ikony ber z Lucide React.
- Komponenty piš jako funkcionální komponenty v `.jsx` souborech.
